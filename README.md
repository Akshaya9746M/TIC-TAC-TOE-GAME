# 🎮 Tic Tac Toe Game

## 📌 Project Overview

Tic Tac Toe is a simple, interactive, two-player game developed using Python. Players take turns placing their symbols (X and O) on a 3×3 game board. The game checks for winning combinations after every move and announces the winner or a draw.

This project demonstrates fundamental Python programming concepts through a fun and interactive game.

## ✨ Features

- 🎮 Two-player gameplay
- 🔲 Interactive 3×3 game board
- 🔄 Alternating turns between X and O
- 🏆 Automatic winner detection
- 🤝 Draw detection
- ⚠️ Input validation
- 🚫 Prevents selecting occupied positions

## 🛠️ Technologies Used

- Python
- Jupyter Notebook

## 🎯 Game Rules

1. The game is played on a 3×3 grid.
2. Player X starts the game.
3. Players take turns selecting positions from 1 to 9.
4. The first player to align three symbols horizontally, vertically, or diagonally wins.
5. If all positions are filled without a winner, the game ends in a draw.
